# ExtendedNoteBlock 2.7.1 - Minecraft 26.2

Paper/Purpur command UX update.

- Added `/enb help` and `/enb ?`.
- `/enb` with no arguments shows the complete help page.
- Added topic help such as `/enb help give`, `/enb help set`, `/enb help wand`, and `/enb help projection`.
- Added context-aware TAB completion for root commands, give types, wand actions/properties, projection actions, and common numeric values.
- Numeric candidates are suggestions only; manually entered values still use the existing validation ranges.
- CI verifies that help and `onTabComplete` are present in the final transformed Paper source before building.

Versions:
- Full Fabric / Paper Client: 2.7.1
- Paper/Purpur Server: 0.8.1
