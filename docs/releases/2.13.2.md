# 2.13.2: English Default and Chinese Language Support

Full Fabric / Paper Client **2.13.2**, Paper Server **0.14.2**, Minecraft **26.2 / Java 25**. CraftEngine **26.8.2** remains required for Paper Server.

- Paper Server messages and ENB item names default to English. The server creates editable `plugins/ExtendedNoteBlockBridge/lang/en_us.yml` and `zh_cn.yml` files on first start. Set `language: zh_cn` in its `config.yml` to use Chinese, then run `/enb reload` or restart. Edits to the selected YAML file also take effect after a reload.
- Full Fabric and Paper Client screens use Minecraft's selected client language. English (`en_us`) and Simplified Chinese (`zh_cn`) GUI translations are included.
- The CraftEngine ENB registration file now gives blocks and items English default names. Server owners can edit those names in `plugins/CraftEngine/resources/enb/configuration/enb.yml` before regenerating CraftEngine's pack.
- Resource-pack delivery and Litematica copying remain as in 2.13.1.

Install the updated Paper Server JAR and ENB CraftEngine resource ZIP after stopping the server and backing up existing plugin data. Existing `config.yml` files must add `language: en_us` (or `zh_cn`) to choose a language; when absent, English is used. The plugin creates missing language files without overwriting existing edits. See the [installation guide](../INSTALLATION.md) and [English setup guide](../../README.md).

Automated builds and startup checks do not replace an in-game check of menus and messages in both languages.
