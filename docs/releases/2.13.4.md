# 2.13.4: Fully Loaded Server Polling

Full Fabric / Paper Client **2.13.4**, Paper Server **0.14.5**, for **Minecraft 26.3 / Java 25**.

## Changes

- When all registered ENB objects are loaded, poll the ledger entries directly and reuse their object types. This avoids a second registry lookup for every object each tick.
- With only some chunks loaded, continue polling the active positions only. Unloaded objects remain saved and never force chunk loading.
- Preserve one-tick redstone polling, independent projection playback timing, wireless power, all note parameters, Litematica metadata, CraftEngine registration and optional listener audio with player preferences.
- Add regression coverage for chunk unload/reload and repeated registration. Client features, language behavior and audio assets are unchanged.

## Downloads and requirements

| File | Install on |
| --- | --- |
| `ExtendedNoteBlock-Full-Fabric-2.13.4-mc26.3.jar` | Single-player or Fabric server/client |
| `ExtendedNoteBlock-Paper-Client-Fabric-2.13.4-mc26.3.jar` | Fabric client connecting to Paper / Purpur |
| `ExtendedNoteBlock-Paper-Server-0.14.5-mc26.3.jar` | Paper / Purpur 26.3 server |
| `ExtendedNoteBlock-CraftEngine-2.13.4-mc26.3.zip` | ENB registration resources for CraftEngine on the server |

**CraftEngine 26.9.2 is required for Paper Server.** The registration ZIP does not include the CraftEngine plugin. Fabric uses Loader **0.20.1** and Fabric API **0.165.0+26.3**. Automatic Litematica transfer optionally uses Litematica **0.29.1** and MaLiLib **0.30.2**. Install only one of Full Fabric and Paper Client.

## Upgrade

Stop the server normally and back up the ENB and CraftEngine data directories. Replace the old ENB plugin JAR, and retain existing music, projections, configuration, optional-audio files and `optional-audio-players.txt`. There is no saved-data migration. Existing 2.13.3 CraftEngine registration resources remain compatible; new installations can use the ZIP above.

CraftEngine generates and hosts the complete resource pack; ENB sends it and tracks loading. Preserve the existing pack hosting and split-audio settings. See the [installation guide](../INSTALLATION.md) for the single delivery flow. No separate `Server-Resources` download is needed.

## Performance limits

An isolated 8,879-object mock replay compares empty, partially loaded and fully loaded working sets, including index rebuilding. It measures bridge polling CPU, allocations and block-query counts. Mixed-scenario JVM runs showed substantial CPU variation, so this release does not guarantee a speedup for every workload. Real CraftEngine calls, world access and music playback costs are outside that replay. Production TPS/MSPT and client FPS require separate measurement. See the [performance notes](../PERFORMANCE.md).
