# ExtendedNoteBlock 2.8.1 — Minecraft 26.2

This hotfix repairs the Paper Client 2.8.0 startup crash and updates the Paper/Purpur plugin to **0.8.2**.

## Fixes

- **Paper Client startup:** moved `BridgeSoundEngineMixin` into its own `bridgeclient.mixin` package. The previous package also contained `PaperBridgeClient` and ordinary GUI classes, which Mixin refused to load with `IllegalClassLoadError`.
- **Sound:** retains the unrestricted ENB pitch factors used for MIDI 0–127. The 48-block attenuation override now applies only to ENB sounds; vanilla sounds keep their normal attenuation and pitch clamp.
- **Resource packs:** fixed missing `min_format` / `max_format` fields that caused the built-in Visuals pack to be disabled. Bundled default sound-pack metadata and newly generated sound packs now target format 88 (Minecraft 26.2).
- **Paper Server:** GUI saves now require the same `extendednoteblockbridge.use` permission as `/enb` (OP by default). Malformed packets and distant, unloaded or out-of-world targets are rejected before accessing a block.
- Existing Paper channels and `objects.yml`, `notes.yml`, `projections.yml` remain compatible. Full Fabric content and the Paper-safe Litematic carrier/metadata behavior remain available.

## Validation and remaining limits

The release workflow builds Full Fabric, Paper Client, Paper Server and Visuals. It runs the existing export tests, Mixin package regression tests and Paper payload tests, and launches the **packaged Paper Client** with Fabric under a virtual display. After resource loading, that startup test checks active, compatible built-in visuals, the loaded vanilla-carrier selector, the note editor, the absence of custom ENB Block/Item registry IDs, all 128 MIDI pitch factors inside SoundEngine, and vanilla pitch/attenuation behavior.

These automated checks do **not** establish actual Purpur multiplayer behavior or audible sample quality. Please still listen to MIDI **0 / 12 / 24 / 36 / 48 / 60 / 72 / 84 / 96 / 108 / 120** and check GUI saving on your server. Paper Litematic pasting still needs the future import protocol to restore ENB parameters automatically.
