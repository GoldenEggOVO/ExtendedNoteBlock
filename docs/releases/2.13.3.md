# 2.13.3: Minecraft 26.3 and Bounded Server Polling

Full Fabric / Paper Client **2.13.3**, Paper Server **0.14.4**, for **Minecraft 26.3 / Java 25**.

## Changes

- Poll registered objects in loaded chunks, share block queries with CraftEngine and reuse stable render states. Redstone keeps its one-tick polling and projection playback keeps an independent timer.
- Preserve unloaded object records, known wireless power, all note parameters and both Litematica transfer formats. The chunk index is runtime-only; no saved-data migration is required.
- Include the existing optional-audio mode, per-player preferences and separate base/audio pack identities. English is the default; Chinese remains available.
- Adapt Full Fabric and Paper Client APIs, resource metadata and optional Litematica integration to Minecraft 26.3. Fabric Loader 0.20.1, Fabric API 0.165.0+26.3, Litematica 0.29.1 and MaLiLib 0.30.2 form the build baseline.
- Paper Server compiles against Paper API 26.3 and CraftEngine 26.9.1; CraftEngine remains required. Preserve existing optional-audio settings and files when upgrading.

Fabric baseline: Loader **0.20.1**, Fabric API **0.165.0+26.3**. Optional automatic copying: Litematica **0.29.1** and MaLiLib **0.30.2**. Install only one of Full Fabric and Paper Client.

**CraftEngine 26.9.2 is required for Paper Server.** The ENB registration ZIP does not include the CraftEngine plugin. Pack compatibility checks passed with both 26.9.1 and 26.9.2.

## Upgrade

Stop the server normally and back up the ENB and CraftEngine data directories. Replace the old plugin JAR, extract the ENB CraftEngine ZIP into the server root, and retain existing music, projections, configuration and `optional-audio-players.txt`.

CraftEngine generates and hosts the complete pack; ENB sends it and tracks loading. Disable CraftEngine's `resource-pack.delivery.send-on-join` and `resend-on-upload`, and remove `send_pack` from enabled workflows triggered by `reload_pack`, preserving their generation/upload steps. Restart and regenerate the pack. Keep existing optional-audio settings and hosting when using split audio. No separate `Server-Resources` download is needed.

See the [installation guide](../INSTALLATION.md) and [English quick start](../../README.md#quick-start).

## Validation and performance limits

The build passed 89 Java tests, 34 Python checks, and separate Full, Paper Client and Litematica production-client startup checks in Linux/Xvfb. Sound-pack audio samples and saved-data formats are retained.

The fixed 8,879-object mock replay reduced recurring queries to the loaded object count and reduced temporary allocations. Its fully loaded case took more CPU time, so this release does not promise a speedup for every workload. Production TPS/MSPT, client FPS, visual quality and listening experience require separate acceptance. See the [performance notes](../PERFORMANCE.md).
