# ExtendedNoteBlock 2.10.1 · Minecraft 26.2

这是 2.10.0 原版客户端聆听功能的实测修复版。Paper Server 升级为 **0.10.1**。

## 修复内容

- 自动资源包信息现在同时写入 Paper JAR 内的独立 Release metadata。默认 `use-official-release: true`，因此旧的服务器 `config.yml`、开发版占位符或上一个版本的 URL 不会再覆盖当前正式资源包。
- 资源包请求从进服后 1 tick 调整到 40 ticks，并在聊天与控制台明确显示“已发送、已接受、已下载、加载成功或失败”。15 秒仍未成功时会给出可操作的排查提示。
- 新增 `/enb pack status`、`/enb pack resend` 与 `/enb pack test <MIDI> [instrument]`，可查看状态、重新下发或绕过音符盒直接试听指定音高。
- 重新生成监听音色时进行有上限的峰值归一化；SoundFont 极端音区若过轻，会改用最近的有效锚点离线移调。构建会解码检查每个 OGG，低于可听安全阈值时直接失败。当前组合包约 **20.5 MiB**。

2.10.0 的事件表本身包含全部 128 个 MIDI Note，但资源包没有加载时，服务器会退回原版约 MIDI 54–78 的音高范围；部分极端采样也确实过轻。2.10.1 同时修正了这两类“听起来没有全覆盖”的原因。

## 安装与确认

1. 停服并移除旧的 Paper Server JAR，只保留 `ExtendedNoteBlock-Paper-Server-0.10.1-mc26.2.jar`，然后完整重启。
2. 原有 `plugins/ExtendedNoteBlockBridge/` 数据目录可以保留，不需要删除音符或投影数据。
3. 进服后会先看到 ENB 正在下发资源包的聊天信息。客户端若把该服务器的资源包设为“启用”，下载会静默进行；设为“提示”才会出现确认框。
4. 执行 `/enb pack status`，确认状态为 `SUCCESSFULLY_LOADED (MIDI 0-127 listener enabled)`。

若需要自定义托管地址，将 `resource-pack.use-official-release` 设为 `false`，并同时填写自定义 UUID、HTTPS URL 和 SHA-1。

## 能力边界

- MIDI 0–127 的事件和倍率完整覆盖；不过 MIDI 0–15 的实际频率低于或接近人耳与普通扬声器下限，技术上正确播放也可能几乎听不到。
- 原版客户端继续使用 32 种代表音色映射 128 个 GM program；Paper Client 保留完整音色、GUI、坐标模型和高级声音曲线。
- 纯资源包仍无法按世界坐标区分已放置的原版载体，精确的 ENB 世界方块外观需要 Paper Client。
