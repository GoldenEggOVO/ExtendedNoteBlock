# ExtendedNoteBlock 2.11.0 · Minecraft 26.2

本版为只接受服务器资源包、没有安装 Paper Client Mod 的玩家增加已放置 ENB 的轻量世界外观。Paper Server 升级为 **0.11.0**。

## 方块外观

- 已登记的 Extended Note Block 在关闭时六个面统一使用 `a_top.png`，通电时六个面统一使用满亮显示的 `a_top_on.png`。
- 服务器仍在世界中保存真实的 `minecraft:note_block`，只向成功加载组合资源包的玩家发送坐标级客户端假状态；不会创建 `BlockDisplay` 或其他实体。
- 同一 tick 的坐标变化会去重并合并为 multi-block change，按已发送区块过滤；进入区块、切换世界、放置、删除、通电和资源包撤销都会同步或恢复。
- 红石灯及其他原版方块不被占用。组合资源包完整列出 1350 种 Note Block 状态，仅两个预留状态选择 ENB 模型，其余 1348 种显式回退原版音符盒模型。
- 检测到 Paper Client 插件频道后，服务端会跳过或移除简化组合包并恢复真实载体视图；Mod 玩家继续看到原本按音高区分的 ENB 材质和通电变体。

## 安装

1. 停服并移除旧 Paper Server JAR，只保留 `ExtendedNoteBlock-Paper-Server-0.11.0-mc26.2.jar`，然后完整重启。
2. 保留原有 `plugins/ExtendedNoteBlockBridge/` 数据目录；音符、对象和 Projection 数据无需迁移。
3. 普通客户端进服并加载自动下发的 `ExtendedNoteBlock-Server-Resources-2.11.0-mc26.2.zip`。执行 `/enb pack status` 应显示 `SUCCESSFULLY_LOADED`。
4. Paper Client 用户将客户端 JAR 同步更新为 2.11.0；服务器会自动识别 Mod 通道并保留完整渲染。

## 能力边界

- ON 模型的“满亮”只使方块材质自身不受环境黑暗影响，不会像真实光源一样照亮周围方块。
- 原版资源包不能读取 PDC 或服务端坐标，因此实现需要 Paper Server 的逐玩家假状态同步；只安装 ZIP、没有 0.11.0 插件时，已放置方块仍是普通音符盒外观。
- 资源包中的状态覆盖是全局的。极少见的普通音符盒若自然处于 `instrument=custom_head,note=24`，也会对加载该包的玩家显示为 ENB；世界数据与红石逻辑不受影响。
- Paper Client 的精确模型、128 种独立音色和高级声音控制不变；纯资源包模式继续使用 32 种代表音色覆盖 MIDI 0–127。
