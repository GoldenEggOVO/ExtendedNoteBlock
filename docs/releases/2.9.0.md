# ExtendedNoteBlock 2.9.0 · Minecraft 26.2

Paper Litematic 粘贴后，现在可以恢复 ENB 身份、音符参数和投影曲目。

## 本次更新

- Paper Client 的 N 键音乐工坊新增「恢复 ENB」，读取原始投影 `.litematic` 中的 `ExtendedNoteBlockBridge` 元数据，兼容 2.8.0 / 2.8.1 导出的文件。
- 以已粘贴结构底部的红色混凝土发射器为定位点，支持坐标平移、顺时针旋转和 X / Z 镜像。
- Paper Server 0.9.0 分批接收参数，检查权限、世界、距离、已加载区块和全部原版载体后，恢复 Note Block、Transmitter 和 Projection Receiver 的 ENB 登记。
- MIDI 0–127、GM 乐器、力度、延音、延迟、淡入淡出及 Pitch Cents 保留至 `notes.yml`，投影曲目保留至 `projections.yml`，对象登记保留至 `objects.yml`。界面编辑与指挥棒批量修改其他属性时保留 Pitch Cents。
- 读取器、共享协议和界面不依赖 Full Fabric 自定义 Registry；Full Fabric 继续使用真实 ENB 方块及原有导出路径。

## 使用方法

1. 客户端更新 **Paper Client 2.9.0**，服务器更新 **Paper Server 0.9.0**。
2. 用 Litematica paste / Easy Place 放好投影结构，包含底部红色发射器及相邻紫色接收器。
3. 看向该红色混凝土或其上方拉杆，按 **N → 恢复 ENB**。
4. 浏览并读取**原始 ENB 工坊导出的 .litematic**；核对发射器 X / Y / Z，按实际放置方向设置旋转 / 镜像。没有改变方向时保持 0° / 无。
5. 点击「恢复 ENB」，等待已保存提示。右键音符盒可检查参数，拉杆可触发已恢复的投影曲目。

需要 OP 或 `extendednoteblockbridge.import` 权限。默认玩家需距发射器 64 格内，导入最多 75000 个音符。整个目标区域需已加载；缺块、方向错误、区块未加载会明确提示位置，不会在校验失败时留下部分登记。重复恢复会覆盖对应坐标的 ENB 参数。

这是粘贴后的手动恢复入口，尚未自动监听 Litematica 每次放置，也不负责直接生成物理方块。普通原版 Litematic、Full Fabric 方块文件或被其他工具重存后丢失 ENB 根元数据的文件，无法恢复原始音乐参数；请重新从 Paper 工坊导出。

## 验证范围
