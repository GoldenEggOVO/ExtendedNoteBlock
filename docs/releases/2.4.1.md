# ExtendedNoteBlock 2.4.1 — Minecraft 26.2

This is the first finalized three-edition packaging layout.

- `ExtendedNoteBlock-Full-Fabric-2.4.1-mc26.2.jar` — singleplayer / full Fabric server.
- `ExtendedNoteBlock-Paper-Client-Fabric-2.4.1-mc26.2.jar` — optional registry-safe Fabric client for Paper/Purpur.
- `ExtendedNoteBlock-Paper-Server-0.5.1-mc26.2.jar` — Paper/Purpur server plugin.
- `ExtendedNoteBlock-Visuals-2.4.1-mc26.2.zip` — standalone shared visual resource pack.

The Paper Client embeds the same visual assets as an always-enabled built-in resource pack. Paper bridge items use Minecraft 26.2's `minecraft:item_model` data component to select the original ExtendedNoteBlock item models without globally replacing ordinary vanilla carrier items.

Placed Paper bridge blocks intentionally remain vanilla-looking until the position-aware Paper Client renderer is implemented, because a plain resource pack cannot distinguish plugin metadata by world coordinate.
