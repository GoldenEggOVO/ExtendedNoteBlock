# 2.13.1：统一使用 CraftEngine 完整资源包

Full Fabric / Paper Client **2.13.1**，Paper Server **0.14.1**，Minecraft **26.2 / Java 25**。CraftEngine **26.8.2** 是 Paper 服务端必需插件。

- 玩家只需下载 CraftEngine 生成的完整包，包含方块映射、模型与全部 ENB 聆听音色。
- ENB 自动读取 CraftEngine 生成文件和托管地址，核对 SHA-1 后发送；旧 GitHub 独立包配置不再生效。
- 下载、加载、拒绝与失败仍由 ENB 跟踪，保留 `/enb pack status` 和 `/enb pack resend`。
- 本版本不再提供独立 `Server-Resources` 附件；GitHub Releases 仅保留当前正式版。旧版独立包下载地址已停用，旧插件用户应升级。

升级前正常停服并备份配置。安装新的服务端 JAR 和 ENB CraftEngine 注册资源，在 CraftEngine 配置中将 `resource-pack.delivery.send-on-join` 与 `resend-on-upload` 设为 `false`，由 ENB 唯一发送 CraftEngine 生成并托管的完整包；正常重启并重新生成、上传。详细步骤见[安装指南](../INSTALLATION.md)。

Litematica 建筑和工坊投影自动导入功能保持不变：Litematica 0.28.8、MaLiLib 0.29.6；使用命令粘贴、Replace All、关闭 changed-block-only，有 Servux 时关闭 pasteUsingServux。

自动化验证不代替多人实机下载、显示与试听验收。本次不会自动修改运行中服务器的配置或重启服务器。
