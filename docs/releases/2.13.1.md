# 2.13.1: One Complete CraftEngine Resource Pack

Full Fabric / Paper Client **2.13.1**, Paper Server **0.14.1**, Minecraft **26.2 / Java 25**. **CraftEngine 26.8.2 is required for Paper Server.**

- Players download one complete pack generated by CraftEngine, containing block mappings, models, and all ENB listener sounds.
- ENB reads CraftEngine's generated pack and hosting URL, verifies SHA-1, and sends the pack to players. Legacy settings for the separate GitHub pack no longer apply.
- ENB continues to track download, loading, rejection, and failure states. `/enb pack status` and `/enb pack resend` remain available.
- This release no longer includes a separate `Server-Resources` asset. GitHub Releases retains only the current release. Old standalone pack download URLs are no longer available; users of older plugins should upgrade.

## Upgrading

Stop the server normally and back up your configuration before upgrading. Install the new Paper Server JAR and ENB CraftEngine registration resources. In CraftEngine's configuration, set both `resource-pack.delivery.send-on-join` and `resource-pack.delivery.resend-on-upload` to `false`, so ENB is the only sender of the complete pack generated and hosted by CraftEngine. Restart normally, then regenerate and upload the pack.

See the [English setup guide](../../README.md#quick-start) for detailed instructions.

## Litematica

Automatic ENB data import for copied builds and music-workshop projections is unchanged. Use **Litematica 0.28.8** and **MaLiLib 0.29.6**, command paste with **Replace All**, and disable changed-block-only mode. When using Servux, disable `pasteUsingServux`.

Automated checks do not replace multiplayer testing of pack downloads, visuals, and audio. Installing this release requires the server owner to update the configuration and restart the server.
