# ExtendedNoteBlock 2.6.0 - Minecraft 26.2

Paper/Purpur interaction release.

- Right-click a bridge-managed Extended Note Block with Paper Client installed to open the registry-safe editor GUI.
- Saving from the GUI returns MIDI note, instrument, velocity, sustain, delay, fade-in and fade-out to Paper; the server validates block identity, distance and ranges before persisting.
- Right-click Global Redstone Transmitter to inspect global/dedicated Projection mode and live power state.
- Right-click Global Redstone Receiver to inspect its current 0/15 output state.
- Right-click NBS Projection Receiver to inspect timeline/playback status.
- Shift + right-click NBS Projection Receiver to test-play its currently loaded timeline.
- Conductor Wand selection behavior still takes priority when the wand is held.
- Paper remains vanilla-registry-safe; Full Fabric custom Block/Item registries are not exposed to Paper.

Program versions:
- Full Fabric / Paper Client: 2.6.0
- Paper/Purpur Server: 0.7.0
