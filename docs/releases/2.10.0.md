# ExtendedNoteBlock 2.10.0 · Minecraft 26.2

这一版让普通原版客户端只需接受服务器资源包，就能在 Paper / Purpur 服务器欣赏 ENB 音乐。Paper Server 升级为 **0.10.0**；已有 Paper Client 用户仍保留完整编辑与高级声音能力。

## 自动资源包与原版聆听

- 新增 `ExtendedNoteBlock-Server-Resources-2.10.0-mc26.2.zip`，组合 ENB 方块 / 物品资源与监听音色，压缩后约 **18 MiB**。
- 官方 Paper Server JAR 已内置该 Release 资源包的 HTTPS 地址和 SHA-1。玩家进服时自动收到确认提示；成功加载后无需客户端 Mod 即可听 ENB。
- 128 个 GM 乐器编号按相近变体映射到 **32 种代表音色**，每种使用 MIDI 0、12、…、120 共 **11 个锚点**，只依赖原版允许的 0.5–2.0 倍 pitch 即可覆盖 MIDI 0–127。
- 独立保留 MIDI 35–81 的 **47 个打击乐采样**；每个声音有 **8 个逻辑声部别名**，不复制音频也能分别停止常见的重叠音符。
- 资源包只有 **399 个实际 OGG**；音色来自 GeneralUser GS 2.0.2，包内附第三方许可与署名。

Paper Server 只在收到玩家的资源包 `SUCCESSFULLY_LOADED` 状态后使用监听音色。加载中、拒绝或失败时保留原版 Note Block 回退；安装 Paper Client 的玩家继续使用 Bridge 声音协议，不会听到两份声音。

## 安装

1. 将 `ExtendedNoteBlock-Paper-Server-0.10.0-mc26.2.jar` 放入 Paper / Purpur 26.2 的 `plugins/`，移除旧版插件 JAR 并重启。
2. 普通玩家用原版 26.2 客户端加入并接受资源包，即可聆听。
3. 创作者或需要完整音色、GUI、精确世界模型和高级曲线的玩家，安装 Fabric API 与同版 Paper Client。

默认资源包是强制的。服主可在 `plugins/ExtendedNoteBlockBridge/config.yml` 的 `resource-pack.required` 改为 `false`；执行 `/enb reload` 会重新读取配置并向在线玩家发送资源包。自定义托管地址时，必须同时更新 ZIP 的 SHA-1。

## 能力边界

- 组合包包含 ENB 方块模型和材质，但纯资源包无法按服务端坐标区分相同原版载体；背包 ENB 物品可以显示专用模型，已放置方块的精确坐标模型仍需 Paper Client。
- 原版聆听保留音高、乐器类别、力度、延音、延迟和基础空间定位；32 种代表音色不会完整保留 128 个 GM program 之间的细微差异。
- 连续 pitch bend、逐 tick 音量曲线和表达式声源移动仍由 Paper Client 提供。超过 8 个完全相同声音同时重叠时，最早声部可能与复用同一别名的新声部一起停止。
