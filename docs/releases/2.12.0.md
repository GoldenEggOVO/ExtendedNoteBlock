# ExtendedNoteBlock 2.12.0 · Minecraft 26.2

本版将 Paper 原版客户端资源包收敛为**物品材质 + 监听音频**，Paper Server 升级为 **0.12.0**。

## 方块与资源包

- 删除 2.11.0 的坐标级假 Note Block 状态、区块索引和批量刷新逻辑。
- 没有 Paper Client 的玩家始终看到真实的原版载体；放置、右键、区块重载都不会再临时显示 ENB 方块材质。
- 不创建 `BlockDisplay` / `ItemDisplay`，也不覆盖 `minecraft:blockstates/note_block.json`。
- 保留 ENB 背包物品模型与材质，普通载体物品继续显式回退原版模型。
- 删除单独的 `ExtendedNoteBlock-Visuals` ZIP；Paper Client 仍内置物品选择器和完整坐标世界渲染。

## 监听音频质量

- 32 种代表音色继续映射全部 128 个 GM program。
- 每种音色由 11 个整八度锚点提升为 **22 个半八度锚点**（MIDI 0、6、…、126），加上 47 个独立打击乐，共 **751 个实际 OGG**。
- 普通 MIDI 0–127 播放时，原版客户端实时变调最多约 ±3 半音；上一版约为 ±6 半音。
- OGG Vorbis 从 quality 3 提升至 **quality 5**；离线补偿采样使用 SoXR precision 28，并为静音裁剪后的尾部增加 20 ms 淡出，减少变调金属感与尾部爆音。
- 位置声音的单声道与归一化统一取已居中的合成器左主声道，避免少数立体声效果在左右平均时发生相位抵消、产生发空或近乎无声的结果。
- 保留有上限的峰值归一化和逐文件解码检查；过轻、接近削波的采样以及达到 **50,000,000 bytes** 的最终资源包都会让构建失败。

音频来自同一份已核验的 GeneralUser GS 2.0.2 SoundFont。自动检查可以排除缺失、过轻、损坏和超体积，但不同音色的主观听感仍需在游戏内试听。

## 安装

1. Paper / Purpur 服移除旧插件 JAR，安装 `ExtendedNoteBlock-Paper-Server-0.12.0-mc26.2.jar` 后完整重启。
2. 保留 `plugins/ExtendedNoteBlockBridge/` 数据目录；音符、对象和投影数据无需迁移。
3. 默认配置继续为 `resource-pack.enabled: true`、`required: true`、`use-official-release: true`。正式 Paper Server JAR 已写入本版 Server Resources 的 URL 和 SHA-1。
4. Paper Client 用户同步更新到 2.12.0；Full Fabric 用户使用同版 Full JAR。

客户端将服务器资源包设置为“启用”时可使用缓存并静默加载；设置为“提示”时由客户端显示确认。由于 `required: true`，拒绝资源包的普通客户端不能继续留在服务器。
