# 2.13.0 · CraftEngine 与 Litematica 自动复制

Full Fabric / Paper Client **2.13.0**，Paper Server **0.14.0**，Minecraft **26.2 / Java 25**。

- Paper Server 现在必须安装 **CraftEngine 26.8.2**；随 Release 提供 ENB 注册资源 ZIP，CraftEngine 插件需单独安装。
- Paper Client 配合 Litematica **0.28.8** / MaLiLib **0.29.6** 保存现有建筑时保存完整 ENB 元数据，命令粘贴完成后自动导入。
- Paper 音乐工坊投影粘贴后自动导入，无需再手动指定发射器。旧 Paper 工坊元数据继续兼容。
- 保留音符参数、投影时间轴和坐标变换；服务端校验权限、区块、范围、方块类型和传输上限。
- 保留旧 ENB 数据，已登记方块按预算迁移；不扫描转换普通世界方块。

升级前正常停服并备份 ENB 与 CraftEngine 数据，移出旧 ENB JAR，安装新插件并将 CraftEngine 资源 ZIP 解压至服务器根目录，生成和下发 CraftEngine 资源包。Full Fabric 不需要 CraftEngine。

自动流程针对 Litematica 命令粘贴，选择 **Replace All** 并关闭 **changed-block-only**；装有 Servux / LitematicaFolia 时还需关闭 `pasteUsingServux`。Servux Direct Paste 不会触发此自动流程，Easy Place 逐块搭建仍使用手动恢复。没有 ENB 元数据的旧建筑文件需要从源建筑重新保存。参见[安装指南](../INSTALLATION.md)。

自动化测试验证协议、数据和构建；Minecraft 多人画面及真人试听仍需实机验收。
