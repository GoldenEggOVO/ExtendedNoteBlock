# ExtendedNoteBlock 2.4.2 — Minecraft 26.2

Finalized three-edition packaging with a no-pack-safe visual fallback.

- `ExtendedNoteBlock-Full-Fabric-2.4.2-mc26.2.jar` — Full content mod for singleplayer / full Fabric servers.
- `ExtendedNoteBlock-Paper-Client-Fabric-2.4.2-mc26.2.jar` — optional registry-safe Fabric companion for Paper/Purpur, with the shared visual pack built in and always enabled.
- `ExtendedNoteBlock-Paper-Server-0.5.2-mc26.2.jar` — Paper/Purpur bridge server plugin using vanilla carriers + PDC only.
- `ExtendedNoteBlock-Visuals-2.4.2-mc26.2.zip` — standalone copy of the same shared visual assets.

## Visual compatibility fix

Paper bridge items no longer require a server-forced custom `item_model` component. The visual pack uses Minecraft 26.2's item-model `minecraft:component` condition with the Bukkit `extendednoteblockbridge:enb_type` PDC marker stored in `minecraft:custom_data / PublicBukkitValues`.

Each carrier selector has an explicit vanilla fallback. Therefore:

- marked ENB item + Paper Client/Visuals pack -> original ENB model;
- ordinary carrier item -> vanilla model;
- no client mod and no resource pack -> vanilla carrier model, never a missing ENB model.

Placed Paper bridge blocks remain vanilla-looking until position-aware client rendering is implemented, because a resource pack alone cannot distinguish plugin PDC by world coordinate.
