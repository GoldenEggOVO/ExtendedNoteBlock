# Security Policy

[Home](README.md) · [Contributing](CONTRIBUTING.md)

## Supported versions

Security fixes are provided for the latest published Minecraft 26.2 release only. Older source and release notes remain available for history, but archived versions are not actively supported.

## Report a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/GoldenEggOVO/ExtendedNoteBlock/security/advisories/new). Do not open a public issue for vulnerabilities involving crafted plugin messages, permissions, resource-pack delivery, unsafe file handling, denial of service or unintended server/client data exposure.

Include the affected ENB edition and version, Minecraft and Java versions, server or loader build, reproduction steps, impact and any suggested mitigation. Remove credentials, player data and unrelated server information. Please allow maintainers time to reproduce and prepare a coordinated fix before public disclosure.

Ordinary crashes, compatibility problems and audio defects can use the public issue forms unless they expose a security boundary.
